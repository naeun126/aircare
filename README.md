# 🌱 AirCare

전국 대기질 데이터를 조회·분석하고, 공식 예보와 상황별 대응 방법을 한곳에서 확인하는 Streamlit 웹앱입니다.

- 배포 주소: https://aircare-program.streamlit.app/
- 깃허브: https://github.com/naeun126/aircare

## 프로젝트 소개
AirCare는 공공데이터를 활용해 전국의 대기질을 조회하고, 주요 대기오염물질의 상태를 분석하며 공식 대기질 예보를 확인하는 프로그램입니다. 측정값에 따라 좋음·보통·나쁨·매우 나쁨 등급을 색상으로 보여 주고, 등급에 맞는 행동 요령을 안내합니다.

- 사용 데이터: 한국환경공단 에어코리아 대기오염정보 OpenAPI (공공데이터포털)
- 사용 기술: Python, Streamlit, pandas, pydeck
- 등급 색상과 안내는 프로젝트용 참고 기준이며 공식 환경기준이나 건강 판단 기준이 아닙니다.

## 사용법
1. 왼쪽 메뉴에서 **전국 대기질 조회**를 엽니다. 시도를 고른 뒤 `최신 대기질 데이터 불러오기`를 누릅니다.
2. 측정소를 선택하면 현재 대기질 요약과 6개 물질의 최신 측정값이 나옵니다.
3. **대기질 분석**에서 분석할 물질을 고르면 평균·최고·최저 농도, 변화 추세, 측정소별 그래프와 지도를 볼 수 있습니다.
4. **대기질 예보**에서는 선택한 지역의 내일 예보를 확인합니다.
5. **대기질 대응방법**에서는 측정소를 고르면 현재 등급에 맞는 행동 요령을 확인합니다.

※ 2~5번 기능은 1번에서 조회한 지역을 이어서 사용합니다. 먼저 1번에서 지역을 선택하고 데이터를 불러오는 것을 권장합니다.

## 주요 기능
| 페이지 | 기능 |
|---|---|
| 📡 전국 대기질 조회 | 17개 시도 선택, 측정소 목록(가나다순), PM10·PM2.5 종합 등급 카드, PM10·PM2.5·O₃·NO₂·CO·SO₂ 최신 측정값 |
| 📊 대기질 분석 | 물질별 평균·최고·최저 농도, 변화 추세, 측정소별 농도 막대그래프, 물질 6종 등급 색상 지도 |
| 🔮 대기질 예보 | 에어코리아 공식 예보 기준 내일의 PM10·PM2.5 예보, 선택 지역 등급, 다른 지역 PM10 예보, 예보 종합 정보(발생 원인·대응 요령) |
| 💡 대기질 대응방법 | 물질 6종 등급 판정, 가장 나쁜 등급 기준 대응 안내, 오염물질 6종별 행동 요령 카드 |

### 등급 기준 (참고용)
| 물질 | 좋음 | 보통 | 나쁨 | 매우 나쁨 |
|---|---|---|---|---|
| PM10 (㎍/㎥) | 30 이하 | 31~80 | 81~150 | 151 이상 |
| PM2.5 (㎍/㎥) | 15 이하 | 16~35 | 36~75 | 76 이상 |
| 오존 (ppm) | 0.030 이하 | 0.031~0.090 | 0.091~0.150 | 0.151 이상 |
| 이산화질소 NO₂ (ppm) | 0.030 이하 | 0.031~0.060 | 0.061~0.200 | 0.201 이상 |
| 일산화탄소 CO (ppm) | 2 이하 | 2.01~9 | 9.01~15 | 15.01 이상 |
| 아황산가스 SO₂ (ppm) | 0.020 이하 | 0.021~0.050 | 0.051~0.150 | 0.151 이상 |

## 실행 방법
1. 저장소를 내려받고 패키지를 설치합니다.
```bash
git clone https://github.com/naeun126/aircare
cd aircare
pip install -r requirements.txt
```
2. [공공데이터포털](https://www.data.go.kr)에서 "한국환경공단 에어코리아 대기오염정보"를 활용 신청해 인증키를 발급받습니다.
3. 프로젝트 폴더에 `.streamlit/secrets.toml` 파일을 만들고 인증키를 넣습니다.
```toml
service_key = "발급받은_인증키"
```
4. 앱을 실행합니다.
```bash
streamlit run main.py
```
Streamlit Community Cloud에 배포할 때는 앱 설정의 Secrets에 같은 내용(`service_key = "..."`)을 입력합니다.
